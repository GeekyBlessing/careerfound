# API Reference

Base URL: `/api/v1`. Full interactive docs (Swagger UI) are auto-generated by
FastAPI and served at `/docs` when the backend is running
(`http://localhost:8000/docs`).

All authenticated endpoints require `Authorization: Bearer <access_token>`.
Errors follow `{ "data": null, "error": { "message": "...", "code": "..." } }`.

## Auth

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | — | Create an account, returns tokens |
| POST | `/auth/login` | — | Returns access + refresh tokens |
| POST | `/auth/refresh` | — | Exchange a refresh token for a new access token |
| POST | `/auth/google` | — | Integration point (501 until `GOOGLE_OAUTH_CLIENT_ID` is set) |
| GET | `/auth/me` | ✓ | Current user |

## Users

| Method | Path | Description |
|---|---|---|
| GET | `/users/me` | Current user profile |
| PATCH | `/users/me` | Update profile fields |
| PATCH | `/users/me/beginner-mode?enabled=true` | Toggle "I Know Nothing" mode |

## Config

| Method | Path | Description |
|---|---|---|
| GET | `/config` | Public feature flags (google auth enabled, payments enabled, ai provider, environment) |

## Careers & Assessment

| Method | Path | Description |
|---|---|---|
| GET | `/careers` | List all active career paths |
| GET | `/careers/{slug}` | Career path detail |
| POST | `/assessment` | Submit the "Find Your Tech Path" questionnaire → 3-tier AI recommendation |
| GET | `/assessment/latest` | Most recent assessment result |

## Roadmap

| Method | Path | Description |
|---|---|---|
| POST | `/roadmaps` | `{path_slug}` → create/return the user's active roadmap for that path |
| GET | `/roadmaps/active` | Full roadmap with phases, lessons, projects, quizzes, progress |
| GET | `/lessons/{id}` | Lesson detail |
| GET | `/lessons/{id}/exercises` | Exercises for a lesson (no answer keys included) |
| GET | `/projects/{id}` | Project detail |
| GET | `/quizzes/{id}` | Quiz detail (no correct answers included — scored server-side) |
| POST | `/lessons/{id}/complete` | Mark a lesson complete |
| POST | `/exercises/{id}/submit` | `{answer}` → `{correct}` |
| POST | `/projects/{id}/submit` | Mark a project complete |
| POST | `/quizzes/{id}/submit` | `{answers: {question_id: option}}` → `{score}` |

## Dashboard / Skill Graph / Readiness

| Method | Path | Description |
|---|---|---|
| GET | `/dashboard` | Full dashboard payload (today's mission, readiness, streak, next action) |
| GET | `/dashboard/mission/today` | Just today's mission |
| GET | `/skill-graph` | Nodes + edges + per-user mastery for the active roadmap's path |
| GET | `/readiness-score` | Current Tech Readiness Score breakdown + next actions |

## Simulations

| Method | Path | Description |
|---|---|---|
| GET | `/simulations?path=cybersecurity` | List scenarios for a path |
| POST | `/simulations/{id}/attempt?chosen_option=b` | Submit an attempt → `{correct, explanation_md}` |

## AI Mentor

|---|---|---|
| POST | `/mentor/chat` | `{conversation_id?, message}` → reply + follow-ups + full history |

## Portfolio

| Method | Path | Description |
|---|---|---|
| GET | `/portfolio` | List the user's portfolio items |
| POST | `/portfolio/generate` | `{project_id, submission_text}` → AI-drafted description/README/CV/LinkedIn copy |

## Mentorship Marketplace

|---|---|---|
